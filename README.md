# 🌿 Mangrove Monitoring - Egypt's Red Sea Coast

Interactive web map showing decadal changes in mangrove distribution and health along Egypt's Red Sea coast (2016-2025).

## 📊 Features
- 🗺️ AOI boundary with interactive pop-up
- 📈 NDVI rasters showing vegetation health (4 years)
- 🌳 Mangrove masks showing extent (4 years)
- 📅 Year selector for 2016, 2019, 2022, 2025
- 🎨 Interactive legend
- 🔍 Zoom and pan controls

## 📂 Data Sources
- Sentinel-2 imagery (Copernicus Program)
- Google Earth Engine processing
- NDVI threshold: ≥ 0.2
- Analysis period: 2016, 2019, 2022, 2025

## 🗺️ How to Use
1. Open `index.html` in your browser
2. Use layer control (top-right) to toggle layers:
   - AOI Boundary: Shows the study area
   - NDVI Rasters: Shows vegetation health
   - Mangrove Masks: Shows detected mangroves
3. Click on the AOI polygon for statistics
4. Toggle years to see changes
