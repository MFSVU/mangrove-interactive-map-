# 🌿 Mangrove Monitoring - Egypt's Red Sea Coast

Interactive web map showing decadal changes in mangrove distribution and health along Egypt's Red Sea coast (2016-2025).

## Features
- 🗺️ AOI boundaries with pop-up statistics
- 📈 NDVI rasters showing vegetation health
- 🌳 Mangrove masks showing extent
- 📅 Year selector for 2016, 2019, 2022, 2025
- 🎨 Interactive legend

## Data Sources
- Sentinel-2 imagery (Copernicus Program)
- Google Earth Engine processing
- NDVI threshold: ≥ 0.2

## How to Use
1. Open `index.html` in your browser
2. Use layer control (top-right) to toggle layers
3. Click on AOIs for statistics
4. Toggle years to see changes
